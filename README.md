# multilevel-commuter-rail
<img width="5456" height="3321" alt="Morristown_Express" src="https://github.com/user-attachments/assets/ce2915e0-1463-48d1-bfd9-0f5892a5f6fe" />

Double-decker commuter rail variants based on the MultiLevel coaches used by NJT. Also come with their own track type due to how Subway Builder is coded, but you should just use the default diesel/electric tracks instead to ensure better compatibility.

Needs game version 1.7.12 or greater!
